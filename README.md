# SHOWROOMKU

Website company profile showroom mobil. Dibuat sebagai tugas akhir **Weekly Meet Catalyst – Build Together: Collaborative Mini Project**.

## Tujuan Project
SHOWROOMKU membantu calon pembeli mengenal showroom, melihat katalog mobil yang tersedia, dan menghubungi tim penjualan dengan mudah. Website ini statis (HTML, CSS, JavaScript dasar) dan dikerjakan bersama lewat workflow GitHub: Issues, branch, commit, Pull Request, dan review.

## Fitur / Section
- **Navbar**: navigasi antarseksi, menu responsif di layar kecil.
- **Home / Hero**: pengenalan showroom dan tombol menuju katalog dan kontak.
- **About / Profile**: latar belakang, visi-misi, dan nilai layanan.
- **Main Content (Katalog)**: daftar mobil dengan filter tipe.
- **Contact & Footer**: informasi kontak, formulir yang membuka WhatsApp, dan footer.

## Teknologi
HTML5, CSS3, JavaScript dasar (tanpa framework, tanpa backend). Git dan GitHub untuk kolaborasi.

## Cara Menjalankan Secara Lokal
```bash
git clone https://github.com/asfafaturahman-creator/showroomku.git
cd <asfafaturahman-showroomku>
```
Lalu buka `index.html` di browser (klik dua kali, atau gunakan ekstensi Live Server di VS Code).
